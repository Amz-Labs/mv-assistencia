# MV Assistência — Landing Page

Site estático desenvolvido para a **MV Assistência 24 Horas**, com foco em apresentação institucional, serviços de chaveiro, assistência automotiva, atendimento particular, formulário de candidatura e redirecionamento para WhatsApp.

Projeto preparado para publicação via **GitHub Pages**.
